# Domain

A run has a caller-supplied identity. A receipt describes one stage of that run
with its status and duration. An evidence archive packages one run's receipts,
projection snapshots and audit records for an operator to inspect.

Current behavior is limited to counting receipt inputs and their duration.
Export and retention are new work for the managed journey to plan. No acceptance
verdicts, authored initiatives, generated drafts or model responses are supplied
as fixture data. The CLI's empty ledger is an input, not a workflow result.
